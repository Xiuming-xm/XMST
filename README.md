# XMST

**修暝的服务器工具** —— Minecraft 服务器运行管理工具。

Windows 桌面应用（Rust + egui/eframe，单文件 exe，解压即用），目标是把开服日常要做的事集中到一个窗口里：开服关服、日志与崩溃分析、备份回退、内网穿透、模组与整合包下载、插件扩展。

## 功能

- **服务器管理**：自动识别 Fabric / Forge / NeoForge / Paper 等服务端；启动 / 停止 / 强停、控制台命令、JVM 参数、自动重启与崩溃重启熔断、内存/CPU 采样
- **日志与诊断**：实时日志、汇总日志库（搜索、级别与来源筛选、导出）、崩溃报告分析（给出根因与建议修改的文件，并可一键跳转）
- **备份与回退**：全量 + 增量快照、限速、备份列表与回退（回退前把现有内容移入 `.mcsrv_trash`）
- **内网穿透**：frp / rathole 隧道管理、运行日志与流量统计、随服务器自动起停
- **模组与资源**：Modrinth 搜索安装、MC 百科查询、简介与更新日志翻译（支持自定义术语表）
- **界面**：日间 / 夜间 / 自定义配色；半透明、毛玻璃、亚克力材质；可折叠侧栏与页面动效

## 下载

构建产物按版本放在 [`versions/`](versions/)，同目录附 `SHA256.txt`。

| 版本 | 文件 | 说明 |
|---|---|---|
| 0.1.0-alpha | `versions/0.1.0-alpha/XMST-0.1.0-alpha.exe` | 首个 alpha；Windows 10/11 x64 |

- 运行 Minecraft 服务器需要系统已安装 **Java**。
- 程序未做代码签名，首次运行 Windows 可能提示"未知发布者"，选择"仍要运行"即可。

## 快速开始

1. 运行 `XMST-0.1.0-alpha.exe`；
2. 「服务器列表」→ **添加服务器目录**，选择你的服务端文件夹（含 `server.jar` / `run.bat` 与 `mods/`、`world/` 的那一层）；
3. 选中服务器 → **启动**；「概览 / 文件浏览 / 服务器设置 / 日志」等页签按需使用；
4. 设置页可调整主题、材质、Java 路径、自动备份与测试功能开关。

## 构建

要求：Rust stable、`x86_64-pc-windows-gnu` 目标、MinGW 链接器。

```powershell
cargo build --release
# 产物：target\release\xmst.exe
```

- `.cargo/config.toml` 已配置链接器与依赖镜像；
- `vendor/eframe-0.29.1` 是打过补丁的 eframe 副本（通过 `[patch.crates-io]` 引用），**构建必需**，不要删除。

